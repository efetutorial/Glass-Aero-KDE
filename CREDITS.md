- Aurorae: Se7enAero by Infinality, GPL-2.0, https://store.kde.org/p/1406638/ . Original artwork retained, package identity renamed to Glass Aero.
- Qt widgets and color scheme: Windows7Aero / AeroThemePlasma by DrGordBord, WackyIdeas and Gamer95875, from https://github.com/laivial/aerothemeplasma/tree/master/misc/kvantum/Kvantum/Windows7Aero and https://github.com/laivial/aerothemeplasma/tree/master/plasma/color_scheme . Repository license: AGPL-3.0. Added translucent glass gradient, enabled blur, adjusted readable colors. Original SVG and editable configuration files included.
- Icons: Win11 by yeyushengfan258, using Yaru assets. https://github.com/yeyushengfan258/Win11-icon-theme . Original COPYING (GPL-3.0) and AUTHORS retained; artwork unchanged, theme name changed for an independent install.
- New global-theme defaults, layout, installer, optional KWin script and Kitty appearance configuration: Efe, GPL-3.0-or-later.
